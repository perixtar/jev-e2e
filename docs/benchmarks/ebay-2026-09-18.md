## Models and input contract

- typesafe/jev-1.13, openai/gpt-5.6-luna, anthropic/claude-sonnet-5, all through OpenRouter, pinned to Typesafe, OpenAI and Anthropic respectively. Save fresh original-provider pricing and resolved model identifiers. No fallbacks, Flex, batch, paid warm-ups, prompt repair, retry or conversation history.
- One shared authored test plan. Natural-language planning, autonomous exploration, recovery and screenshot understanding are excluded. The benchmark measures grounding each requested action to an observed UI control.
- Jev uses its native typed-choice endpoint /api/alpha/decisions. Chat models use /api/v1/chat/completions with strict JSON schema, reasoning disabled and 96 output tokens. There is one target-choice question. Formatting overhead is billed.
- Common observation policy: visible DOM elements, at most 240 controls, at most 220 compatible choices and 8,000 characters of text. Traverse open shadow roots, including the actual protection dialog, and visible frames within dialogs. When a dialog is open, restrict observations to that dialog. Exclude aria-hidden controls. Include observed listing IDs on product links. Literal input values, verifier selectors, expected prices and action-oracle IDs are not sent as answers or hidden ground truth. The desktop page needs a larger common control budget to include its sidebar filters and product cards.
- Wait up to 12 seconds for each authored direct control to render, analogous to browser auto-waiting. Waiting and observation are included in elapsed time. Every completed action has exactly one paid decision; absent controls produce a runner/site block without a fabricated model response.
- Accept all equivalent visible links to the same frozen listing, including duplicate sponsored and ordinary cards. Record agreement with the independent action oracle. Stop an incorrect control choice before dispatch; do not mutate unrelated products.
- Unlike the local demo, live eBay DOM text, advertisements, ranking and counters can vary between runs. Save every input document and its SHA-256 hash. Claim identical observation rules and workload, not identical bytes or perfectly frozen live-site data.

## Browser and execution

Use one identical Chromium build, headed, fresh guest context per trial, default desktop browser identity, custom 1280 × 800 viewport and device scale factor 1. Service workers use the browser default. No personal browser profile or shopping cart is used. Reuse the existing jev-e2e action executor and its control-fingerprint checks; its code was unchanged throughout the measured batch.

Keep links on the recorded page by setting target=_self for external-tab links, identically in every arm. Fill the exact authored quantities and commit them with Tab. Native site navigation, DOM waiting, UI execution and independent assertions count toward elapsed time. Browser creation, initial homepage navigation, recording calibration, final screenshots and recording finalization do not.

Initial navigation waits for the normal browser load event followed by a five-second readiness wait, outside the measured test. Subsequent navigation also waits for the load event and counts toward test time. This permits the site's normal scripts to initialize; no script, cookie or security protection is spoofed or suppressed.

Use one second of idle time before every action in all arms, including unpaid preflight, to pace live-site traffic. This pacing is included in workflow elapsed time and excluded from API round-trip latency. After each action, use identical bounded DOM settling. Requests have 30-second timeouts; cases have 240-second limits. Preserve failures, blocks and partial costs. No automatically repeated mutation. Website errors, authentication requirements, changed inventory and provider/budget blocks are reported separately from semantic choice accuracy.

## Repetitions, quota and scoring

Three first-attempt trials per model, sequential and balanced: Jev/GPT/Claude; GPT/Claude/Jev; Claude/Jev/GPT. Record all nine trials and preselect round 1 recordings for the video, including failures.

There are 16 model calls per complete trial, fitting the observed GPT new-account 20/minute quota. Wait at least 65 seconds since that model's last request before starting another case; between-case waits are excluded from timers. If the provider still blocks a request, retain the original block and do not silently replace the trial.

Report full-case PASS count out of all three attempts, correct-control decisions, independently passed website checkpoints, successful full-workflow median/range, median/p95 full API round trip and actual numeric usage.cost. Partial failure time/cost is listed separately and cannot win a full-workflow speed comparison. Report provider cache and reasoning-token usage.

The full guest variation has 31 authored website checks. No bugs are injected into eBay. This is one known-state shopping workflow, not a broad accuracy benchmark or proof of bug-detection ability.
